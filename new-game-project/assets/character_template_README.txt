Character sprite template

Canvas: 288 x 640 px, transparent PNG
Frame size: 96 x 160 px
Rows: front/down, left, right, back/up
Columns: three walk-cycle frames per direction

Draw inside each frame. Use the faint center line to keep the character centered and the red guide as the shared ground line. The guides are only for drawing; erase/hide them before importing the finished sprite sheet.

The current player.tscn uses 96 x 160 atlas regions at scale 0.25. Keep the finished sheet at this canvas size and replace the texture path in player.tscn when ready.
